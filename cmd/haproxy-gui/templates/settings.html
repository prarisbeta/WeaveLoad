Pengaturan

Pengaturan tingkat aplikasi ini terpisah dari konfigurasi HAProxy. Perubahan di sini tidak memuat ulang HAProxy.

Koneksi Redis (untuk antrean/queue)

Setiap kali suatu alamat IP melebihi Batas Laju (Rate Limit) sebuah pool, kejadiannya dikirim sebagai satu baris JSON ke antrean Redis (list haproxy:ratelimit:events), siap diproses sistem lain seperti pencatatan insiden atau notifikasi. Selalu tekan "Uji Koneksi" terlebih dahulu. Kalau berhasil, baru tekan "Simpan". Kosongkan Host untuk menonaktifkan fitur ini.

Token API Konsumsi Antrean

Sistem eksternal atau modul Incident Management mengonsumsi antrean lewat POST /api/queue/ratelimit-events/consume dengan header Authorization: Bearer <token>. Setiap panggilan mengambil dan menghapus kejadian dari antrean (bukan sekadar melihat; lihat halaman Antrean untuk itu). Buat token baru untuk menonaktifkan token lama.
