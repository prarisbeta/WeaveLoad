Koneksi Redis (untuk antrean/queue)

Setiap kali suatu alamat IP melebihi Batas Laju (Rate Limit) sebuah pool, kejadiannya dikirim sebagai satu baris JSON ke antrean Redis (list haproxy:ratelimit:events) — siap diproses sistem lain (mis. pencatatan insiden, notifikasi). Selalu tekan "Uji Koneksi" dulu — kalau berhasil, baru tekan "Simpan". Kosongkan Host untuk menonaktifkan fitur ini.
