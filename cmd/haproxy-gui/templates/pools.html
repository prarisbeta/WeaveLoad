Buat Pool Baru

Ikuti 3 langkah ini untuk membuat kelompok server baru. Pengaturan lanjutan (SSL, sesi lengket, ACL) tidak ada di sini — tambahkan lewat menu Konfigurasi setelah pool ini jadi, kalau memang perlu.

1

Nama & cara membagi trafik

Nama ini yang akan muncul di daftar Pools dan dipakai saat mengatur rute domain.

2

Pemeriksaan kesehatan

Kosongkan kalau tidak yakin — HAProxy akan memeriksa server hanya lewat koneksi TCP biasa, yang sudah cukup untuk kebanyakan kasus.

3

Server pertama

Pool tidak boleh kosong — isi setidaknya satu server. Anggota lain bisa ditambahkan setelah pool ini dibuat.
