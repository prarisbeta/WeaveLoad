🤖 Setup Integrasi MCP (Model Context Protocol) & AI

v1 REST API Ready

Hubungkan asisten AI (Google Antigravity, Claude Desktop, Cursor, Claude Code) ke Konsol Gateway untuk pemantauan live health, investigasi insiden, dan mitigasi dengan prinsip Human-in-the-Loop.

Simpan konfigurasi di atas ke file .agents/mcp_config.json pada root workspace project Anda.

Tool Name Kategori Deskripsi Otoritas
